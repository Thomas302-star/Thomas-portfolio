# Thomas Fatade Portfolio

Personal portfolio website for Thomas Fatade, focused on modern websites for brands and businesses.

## Stack

- Next.js
- TypeScript
- Tailwind CSS
- Motion
- GitHub
- Vercel

## Design system

- Display font: Satoshi
- Body/UI font: Inter
- Deep Black: `#0A0A0A`
- Off White: `#F5F5F2`
- Electric Blue: `#2563EB`

This repository currently contains the project foundation only. Portfolio features will be built incrementally and tested before moving to the next feature.
